# Connected in Praise 2026 🎵✝️

> **Every Voice. Every Story. Connected in Praise.**  
> An annual praise and worship evangelism concert hosted by **Jerusalem Choir** in strategic partnership with **Adventist Possibility Ministries (APM)**.  
> **Date:** November 4–7, 2026  
> **Venue:** Convocation Arena, Rivers State University (RSU), Port Harcourt, Nigeria · Livestreamed Worldwide  

---

## 🌟 Vision & Movement

Connected in Praise 2026 is more than a concert — it is a movement dedicated to **breaking disability barriers in worship**. In partnership with Adventist Possibility Ministries, this year's experience is intentionally tailored for:
- **Wheelchair Accessibility:** Wide ramps, barrier-free access, and front-row reserved spaces.
- **Audio & Visual Inclusivity:** Stage sign language interpretation (ASL) and real-time live captions.
- **Dignity & Belonging:** An atmosphere where every person with diverse abilities is honored as a fellow worshipper and minister.

## ⚡ Features & Sections

1. **Accessible Navigation:** Sticky glass header with mobile drawer and one-click High-Contrast Mode toggle.
2. **Hero Experience:** Atmospheric stage lighting, live countdown timer to Nov 4, 2026, dynamic waveform audio animation, and direct CTA buttons.
3. **Key Stats Bar:** Animated metrics highlighting 4 days of worship, 100% inclusion, and infinite reasons to praise.
4. **APM Mission Pillars:** 3 core pillars (Physical Accessibility, Audio/Visual Adaptations, Belonging & Dignity) and the official 2026 Movement Creed.
5. **Interactive Voice Engine:** Tap-to-reveal spiritual anchors ("Why Do You Praise?") with synchronized waveforms.
6. **Jerusalem Choir Spotlight:** Honors the vision bearers and musical host since 2019.
7. **4-Day Itinerary & Timeline:** Interactive tabs across all 4 days with session timings, venues, and livestream indicators.
8. **Visual Archives (Gallery):** Filterable photo gallery with full-screen lightbox modal.
9. **Stories & Interactive Prayer Wall:** Testimonials and a real-time digital prayer wall where worshippers can pin personal prayers and thanksgiving notes.
10. **Contact & Accessibility Desk:** Direct WhatsApp hotline, email, and accessible venue guidance.
11. **Grand Call to Action:** Final movement invitation with livestream subscription link.
12. **Comprehensive Footer:** Back-to-top button, navigation links, and formal inclusion statement.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server with hot reload
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
